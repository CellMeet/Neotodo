萤火虫特效

完成任务的代理，会在 Doing 图标周围留下一小片光。

暗色主题里是萤火虫和几盏小纸灯笼，围着图标慢慢绕、慢慢升；亮色主题换成几粒暖色余烬，从图标边缘向上飘。每一颗光点都有自己的一点光晕，但不会把图标整个包住。

打开子任务的笔记后，对应的光点会自动散去；整组结果都看过之后，整行恢复安静。图标本身的暖色呼吸光是独立的「火光特效」插件，另有「白色闪电」插件会劈下自然闪电。
