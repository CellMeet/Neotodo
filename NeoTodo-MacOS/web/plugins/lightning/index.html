白色闪电

完成任务的代理，会让 Doing 图标被一团白色的闪电包住。

它不是一颗球，也不只是几道干脆的直线：是一团团挤在一起、互相缠着的白色细闪电。里层短、外层长，中间不断分叉，边缘的电丝越往外越淡，最后化在纸里。看上去不像一个圆，更像一团毛茸茸的、活着的电。

这团东西会呼吸。三层电弧用不同的节奏一起涨大、缩回、轻微扭转，有些电丝还会突然亮一下、暗一下，所以它不会像循环动画一样准时。闪电本身是白的，只有周围的空气带一点冷蓝。亮色主题会给白色电弧加一圈冷色描边，免得在浅色纸上消失。打开子任务的笔记后，它会立刻停。
