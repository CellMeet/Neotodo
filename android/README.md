# NeoTodo for Android

NeoTodo for Android is a native WebView shell around the **same** Python backend
and web workspace used by the Linux and Windows builds.

Chaquopy embeds CPython 3.12 in the APK, `android_server.py` starts the existing
`app.Store` + HTTP server on `127.0.0.1`, and the WebView loads that local page.
There is no second implementation of categories, todos, subtasks, notes, themes
or archive logic.

## Layout

```text
android/
  app/src/main/python/android_server.py  Android entry point + desktop-only action patches
  app/src/main/java/.../MainActivity      Full-screen workspace + Python startup
  app/src/main/java/.../DetachedActivity   Detached note/AI sheet window
  app/src/main/java/.../WebViewSupport    WebView, JS bridge, IME and file chooser plumbing
  sync-sources.sh                         Copies app.py, startup.py and web/ for the build
  build.sh                                Builds assembleDebug and writes ./NeoTodo-Android.apk
  run-emulator.sh                         Boots the AVD, installs the APK and launches it
```

`app.py`, `startup.py` and `web/` remain the source of truth. The copies under
`app/src/main/python/` are generated by `sync-sources.sh` and ignored by git.

## Build

Requirements:

- JDK 17 or newer
- Android SDK with platform 35, build-tools 35 and platform-tools
- Python 3.12 on the build machine (Chaquopy compiles the target sources)
- Internet access the first time Gradle downloads the Chaquopy runtime

```sh
export ANDROID_HOME="$HOME/Android/Sdk"
./android/build.sh
```

The result is `./NeoTodo-Android.apk` (debug-signed, `arm64-v8a` + `x86_64`).
Install it manually with:

```sh
adb install -r NeoTodo-Android.apk
adb shell am start -n io.github.neotodo/.MainActivity
```

## Emulator

The local test AVD is named `NeoTodo` (API 35, `pixel_tablet`, x86_64):

```sh
./android/run-emulator.sh
```

The script starts the emulator on port 5558, waits for the package service,
installs the APK and opens the app. Override with `NEOTODO_AVD` or
`NEOTODO_PORT` if needed.

## Android adaptations

- The soft keyboard shrinks the WebView through real IME insets, so dialogs and
  inputs stay above it on edge-to-edge Android 15.
- The hidden left tool rail and top utility bar also open from a tap on the
  screen edge, because touch devices have no hover state.
- External links open with an Android `Intent` instead of `xdg-open`.
- Project-folder and user-sound/note-material folder actions report that they
  are desktop-only. Notes, images, sounds and stickers work normally.
- Detached note/AI sheets open as `DetachedActivity` and the short-click
  **home** bridge closes them.
- App data lives at
  `files/.local/share/neotodo/NeoTodo.json` inside the app's private storage.
- The AI terminal expects the `opencode` CLI, which is not bundled in the APK;
  the rest of the workspace does not depend on it.
