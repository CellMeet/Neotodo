NeoTodo 背景音乐 / Background music
==================================

`oborozukiyo.mp3` 是 NeoTodo 可选的主题背景音乐，默认在启动后循环播放。

- 开关位置：Settings → Sound → **Background music**，或右键右上角声音按钮打开的小面板。
- 主声音开关关闭时背景音乐也会暂停；音量滑块同时控制音效和音乐。
- 想换成自己的音乐，用同名 `oborozukiyo.mp3` 覆盖本文件即可（重启后生效）。
- 关掉 Background music 开关后，音效仍然正常播放。
