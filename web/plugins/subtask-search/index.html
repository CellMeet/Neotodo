子任务搜索

一条直角玻璃搜索框，从左栏打开时从子任务上边框滑出。

开启后，左侧工具栏会出现深黑色放大镜。点一下打开搜索栏，再点一下收起。输入关键词后，匹配的子任务会按最近活跃时间从上到下排列，右侧显示几分钟、几小时或几天前；已完成子任务也会一起列出，点击即可回到它原来的位置并选中它，搜索栏保持打开。搜索框有自己独立的一套磨砂玻璃蒙版材质：黑色字直接落在蒙版上，直角裁切，下方的结果框用同一种材质；磨砂的模糊半径在下面的 Blur 里调。

Click 开关搜索栏 Type 按时间排列 Done 已完成也能搜 Blur 调整磨砂半径
