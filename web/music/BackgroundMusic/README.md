NeoTodo 背景音乐 / Background music
==================================

这个文件夹保存 NeoTodo 的背景音乐。程序会把这里的音频文件列在
Settings → Music 的 Background music 下面，点击名字即可切换。

- 初始文件：`BackgourndMusic.mp3`（阴阳师：百闻牌「朧月夜」）
- 添加音乐：把 `.mp3` / `.wav` / `.ogg` / `.flac` / `.m4a` 放进来，重新打开
  Music 设置页即可看到。
- 显示名字：在 `tracks.json` 里给文件配一个 `name`；没有写进清单的文件会用
  文件名作为名字。
- 文件夹按钮：Settings → Music 右上角的文件夹图标会打开运行时的
  `<data>/music/BackgroundMusic/`。
