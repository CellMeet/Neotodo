## 完整说明

```
NeoTodo 是一个把「待办」和「记录」放在同一张桌子上的工具。

■ 待办不是一根列表
每个分类是一张卡片，任务可以拆成子任务、拖动排序、分层叠放。完成时会有一点点
纸片落下的动画，完成的条目收进抽屉，不会一直占着视线。

■ 笔记就在任务旁边
右侧可以拉出笔记面板，随手写、贴图、换纸感材质；也能把笔记和 AI 终端拆成独立
窗口，任务和思考互不打扰。

■ 小功能是按需打开的
番茄钟、音乐、搜索、收纳箱、便签抽屉、社区主题……都是可以自己开关的插件。不
喜欢的插件不会出现在界面上。

■ 你的数据是你的
任务、笔记、主题、设置都是本机上的一个 JSON 文件：没有账号、没有云同步、没有
统计 SDK、没有广告。卸载应用即删除数据。

■ 关于 AI
AI 面板需要你自己准备模型接入方式（本机 CLI 或你自己的 API Key），不配置也不
影响其他功能；应用本身不会把内容发到任何第三方服务器。

适合喜欢干净界面、又想把事情和想法记在一起的人。
```
